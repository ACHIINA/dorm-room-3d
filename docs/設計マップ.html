部屋の暮らし 設計マップ

対象: ミッドセンチュリー大学生の部屋_リアル版 / Godot 版(godot_walk) ・ 最終更新 2026-10-15 ・ 区分: 現状(集中モード + 暮らしの機能 + 昼夜・ドア・廊下 + 315 号室・ラウンジ・シャワールーム + 見た目の仕上げ)

何のための機能か

自分用。部屋のゲームを起動して F を押すと机に座り、ポモドーロタイマーが始まる。残り時間は部屋のモニターと画面の隅に出て、時間になるとチャイムと macOS の通知で知らせる。今日の集中時間を記録する。

暮らしの機能(life.gd)

部屋の物を見て E で使う。毎日 7 つの「今日のこと」があり、全部終えた日が続くと連続日数が伸びる。

昼と夜・ドア・廊下(world.gd)

起動時の実際の時刻で昼(6:00〜17:59)か夜かが決まる。T か目覚まし時計で切り替え。窓から入る光(太陽・月・窓の明るさ・空)は、昼夜・カーテン・雨の組み合わせから 1 か所でまとめて計算する。

状態の移り変わり

集中 → 休憩 を繰り返し、4 回目の集中のあとは長い休憩。Space で一時停止、F でいつでも終了。

stateDiagram-v2
  [*] --> 通常: 起動
  通常 --> 集中: F(机に座る・ランプ点灯・レコード再生)
  集中 --> 休憩: 残り 0(チャイム・通知・記録に追記)
  休憩 --> 集中: 残り 0(チャイム・通知)
  集中 --> 長い休憩: 4 回目の集中が終わる
  長い休憩 --> 集中: 残り 0
  集中 --> 一時停止: Space
  休憩 --> 一時停止: Space
  一時停止 --> 集中: Space(集中中だった場合)
  一時停止 --> 休憩: Space(休憩中だった場合)
  集中 --> 通常: F(途中までの集中も 1 分以上なら記録)
  休憩 --> 通常: F

キー操作

キー通常集中モード中
F集中モードを始める集中モードを終える
Spaceジャンプ一時停止 / 再開
↑ ↓—集中の長さを 5 分ずつ変える(次の集中から)
M小窓モードの切り替え(右下に小さく、常に手前)
E R部屋の物を使う(ランプ・モニター・レコード・カーテン・ケトル・マグ・金魚・じょうろ・植物・天井の照明・窓の雨・カレンダーとノート)、次の曲
Tab今日のこと(ノート)を開く・閉じる
Zベッドで横になっているときに眠る(暗転して今日のまとめ)
Q持っているじょうろを元の場所に置く
P表示を隠して写真を保存(ピクチャ/DormRoom)
T昼と夜の切り替え(目覚まし時計を見て E でも可)

今日のこと(毎日リセット)

項目達成のしかた
集中を2回する集中モードで 25 分(設定した長さ)を 2 回最後まで
植物に水をやるじょうろを持って(棚の横の床)植物を見て E
金魚にえさをやる窓台の金魚鉢を見て E
コーヒーを1杯飲みきるケトル(手前の棚)で淹れて、机のマグを 3 回飲む
レコードを1曲最後まで聴くターンテーブルで再生し、曲が終わるまで
シャワーを浴びるシャワールームのブースでシャワーを見て E(カーテンが閉まり、お湯と湯気と音)
明かりを全部消してから眠るデスクランプ・球形ランプ・モニター・天井の照明を消し、ベッドで横になって Z

保存する情報

Godot の利用者データ用フォルダ(user://)に JSON で保存する。macOS では ~/Library/Application Support/Godot/app_userdata/Dorm Room Walk/。

erDiagram
  DAY ||--o{ SESSION : "1 日に複数の集中"
  DAY { string date "2026-10-15" int minutes "その日の合計(分)" int count "完了した集中の回数" }
  SESSION { string start "開始時刻" int minutes "集中した分" bool completed "最後までやったか" }
  SETTINGS { int focus_min "集中の長さ(既定 25)" int break_min "休憩(既定 5)" int long_break_min "長い休憩(既定 15)" bool autoplay "集中開始でレコードを再生" }
ファイル中身
focus_log.json日付ごとの合計分・回数と、各集中の開始時刻・分・完了したか
focus_settings.json集中・休憩の長さ、レコードを自動で再生するか
life_state.json日付ごとの「今日のこと」の達成、コーヒーの杯数、聴いた曲数、水やりした鉢、金魚のえさ。連続日数と最後に全部終えた日
